# **App Name**: Input Saver

## Core Features:

- Input Field: A simple HTML form with a text input field where the user can enter any text.
- Local Storage Save: After user submits input field data, save data to local storage.
- Input Preview: Display the saved text below the input form for easy preview.

## Style Guidelines:

- Primary color: A calm light-blue (#73A7C9), to project simplicity.
- Background color: Very light blue background (#F0F4F8), near-white and easy on the eyes.
- Accent color: A subtle dark blue accent (#4A6E8A) for the submit button, offering contrast.
- Font: 'Inter', sans-serif, used for both headlines and body, creating a modern feel.
- Simple, centered layout for the input form and text display.
- Gentle fade-in animation for the previewed text after submission.
